## What I build

| Project | What it is | What it demonstrates |
|---|---|---|
| **[SemiBand](https://github.com/gijunpark42-lab/SemiBand)** · [live](https://semiband-dashboard.vercel.app) | A daily trading system for the AI semiconductor chain. Twelve agents score 176 stocks, a Bayesian ridge learner re-weights each by how well its past calls scored, and the blend trades a paper account. The point-in-time replay returns +1,028% at Sharpe 2.14 over 500 sessions against +245% for the same stocks held equal weight, and 51 pre-registered research rounds stand behind it. | Signal research, walk-forward learning, execution, and an evaluation protocol that rejects things |
| **[reticulum-ai](https://github.com/gijunpark42-lab/reticulum-ai)** · [live](https://gijun42.com) | A 380-company, 1,430-edge graph of the AI and semiconductor supply chain across 21 product chains, built from 1,149 source documents: 622 earnings calls, 421 SEC filings (10-K, 10-Q, 8-K) and 96 investor conferences. Includes an event study on hand-labeled "capacity sold out" signals across 71 calls (abnormal returns vs. SOXX/SPY/QQQ, t-tests, hit rates). | Data engineering, event-study methodology, sector depth |
| **[CellulaML](https://github.com/gijunpark42-lab/CellulaML)** · [live](https://cellulaml.vercel.app) | Cell-type labeling for single-cell data that runs entirely in the browser, so no data is uploaded. 96.3% correct on donors it had never seen, and 97% correct on the 98% of cases it chooses to answer. | Applied ML with calibrated abstention |
| **[spactrum42](https://github.com/gijunpark42-lab/spactrum42)** | SPAC merger dilution analyzer: pro forma cap table, net cash per share, and premium or discount to NAV across the full 0-100% redemption spectrum. Pure TypeScript math engine verified by a Vitest suite (golden-master, monotonicity, ownership-sum tests). | Deal mechanics, cap-table math, tested and dependency-free code |
| **[skhynix-premium](https://github.com/gijunpark42-lab/skhynix-premium)** · [live](https://skhynix-premium.vercel.app) | Real-time tracker of the SK hynix NASDAQ ADR premium over its Seoul listing (KRX 000660), FX-adjusted at the 10-ADS ratio, across KRX regular and NXT sessions and US pre/after-market hours. | Cross-listing mechanics, real-time data plumbing |
| **[inbox-calendar](https://github.com/gijunpark42-lab/inbox-calendar)** | Moacal: a mobile app that turns emails, chat messages and screenshots into calendar events. An agent extracts the appointment, checks it against the existing calendar, and proposes free slots when it conflicts. Handles Korean relative dates and substitute holidays, and drafts the reply in the sender's language. | Agent routing, multilingual extraction, mobile |
